Mục tiêu

Tab này hướng dẫn cấu hình API theo từng nền tảng để hệ thống lấy được chi phí quảng cáo về UI, phục vụ theo dõi lợi nhuận và cảnh báo hành động khẩn cấp. Đây là nơi nhập token quảng cáo Meta/Google/TikTok/Zalo, không dùng để nhập OpenAI API Key cho chatbot.

1) Điều kiện dữ liệu bắt buộc trước khi đồng bộ

  • Mỗi nhóm quảng cáo gắn đúng 1 sản phẩm (đã khóa cứng theo nghiệp vụ hiện tại).
  • Mỗi bản ghi nhóm quảng cáo cần có mã định danh duy nhất từ nền tảng (Meta adset_id, Google ad_group_id, TikTok adgroup_id).
  • Ads provider token phải gắn đúng tài khoản quảng cáo để đối soát chi phí theo ngày.
  • Múi giờ báo cáo cần thống nhất với hệ thống (khuyến nghị Asia/Ho_Chi_Minh).

2) Cấu hình Facebook (Meta)

  1. Tạo App tại Meta for Developers và bật quyền Marketing API.
  2. Xin quyền tối thiểu: ads_management, ads_read, business_management.
  3. Lấy Access Token dài hạn cho user hệ thống hoặc system user của Business.
  4. Trong tab Danh sách Ads token, bấm Thêm Ads Token và nhập đúng act_XXXXXXXX.
  5. Dùng nút Test kết nối để xác thực tài khoản quảng cáo trước khi chạy đồng bộ tự động.

API tham chiếu: GET /act_{ad_account_id}/insights?level=adset&time_range... để lấy spend theo ad group.

3) Cấu hình Google Ads

  1. Tạo OAuth Client trên Google Cloud, bật Google Ads API.
  2. Tạo Developer Token trong Google Ads Manager.
  3. Lấy refresh_token và lưu trong Ads API Tokens hoặc Ads API Connections của hệ thống.
  4. Liên kết đúng customer_id của tài khoản chạy quảng cáo.
  5. Đồng bộ dữ liệu qua báo cáo ad group để lấy cost theo ngày.

Trường cần lấy: ad_group.id, ad_group.name, metrics.cost_micros, segments.date.

4) Cấu hình TikTok Ads

  1. Tạo App trong TikTok for Business và xin quyền truy cập Ads API.
  2. Lấy access token hợp lệ cho advertiser.
  3. Khai báo advertiser_id trong token record để map đúng nguồn chi phí.
  4. Đồng bộ dữ liệu cấp adgroup để ghép với nhóm quảng cáo nội bộ.

Trường cần đồng bộ: adgroup_id, adgroup_name, stat_cost, stat_time_day.

5) Quy trình đưa dữ liệu về UI

  1. Thêm Ads token và kiểm tra trạng thái hợp lệ trong tab Danh sách Ads token.
  2. Map ad group nền tảng với nhóm quảng cáo nội bộ (1 nhóm quảng cáo = 1 sản phẩm).
  3. Chạy tác vụ đồng bộ định kỳ theo ngày để ghi chi phí vào MongoDB.
  4. UI ngân sách/quản trị sẽ đọc dữ liệu đã chuẩn hóa từ backend để hiển thị thực tế và dự kiến theo X hoàn.

6) Kiểm tra nhanh khi lỗi dữ liệu

  • Ads token hết hạn hoặc thiếu scope: chi phí trả về rỗng/403.
  • Sai ad account id: test token báo không truy cập được tài khoản.
  • Lệch múi giờ: dữ liệu ngày hiện tại thiếu hoặc lệch 1 ngày.
  • Chưa map ad group: có chi phí API nhưng không ghép được vào nhóm quảng cáo nội bộ.

7) Bảo mật và vận hành an toàn

  • Không lưu Ads token trong mã nguồn; chỉ lưu trong cơ sở dữ liệu và biến môi trường an toàn.
  • Bật cơ chế xoay Ads token định kỳ, ghi chú ngày đổi để dễ truy vết.
  • Giới hạn quyền tài khoản chỉ đủ đọc chi phí quảng cáo.
  • Luôn có backup MongoDB trước khi chỉnh mapping hoặc chạy job đồng bộ lớn.
