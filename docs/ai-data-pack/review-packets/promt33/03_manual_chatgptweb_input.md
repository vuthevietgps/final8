# Manual ChatGPT Web Input

Created:

`docs/ai-data-pack/manual-chatgpt-web-transcript/prompt33_chatgptweb_input.md`

The input prompt tells ChatGPT Web to treat the uploaded JSON as a director/executive analysis packet, not as code.

The requested response structure includes:

1. Executive summary
2. Top risks / abnormalities
3. Cash / receivable / payment pressure
4. Ads / campaign efficiency signals
5. Product / offer / inventory issues
6. Dealer / agent / sales collection issues
7. Operations capacity issues
8. The 12 expected demo findings with exact evidence locations or JSON labels
9. Advisory-only recommendations
10. Explicit no-action-execution statement

The prompt also explicitly bans invented data, executable action files, provider/API mutation instructions, OpenAI API upload, Action Draft Schema, action import, provider validateOnly, provider mutation, and Phase 3.
