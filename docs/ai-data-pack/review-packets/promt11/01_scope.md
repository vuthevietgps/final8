# Scope

Included:

- Export policy for `cached_export`, `official_export`, and `partial_export`.
- Source criticality matrix for Director and Marketer packs.
- Freshness, coverage, quality, and no-false-zero policy.
- Decision gate policy.
- RBAC and public surface policy.
- Export lifecycle policy.
- Snapshot, artifact, retention, and download policy.
- ChatGPT Web behavior rules.
- Future implementation test plan.

Excluded:

- Source code edits.
- Database migrations.
- Endpoint implementation.
- Public export implementation.
- Provider calls, mutations, or validateOnly.
- Action import, approval workflow, dry-run, or live execution.
- OpenAI/upload.
- Phase 3 work.
