# Operator Execution Guide

Main document:

- `docs/ai-data-pack/rollout-evidence-prep/02_operator_execution_guide.md`

The guide tells humans/operators to capture:

- Environment.
- Operator.
- Time.
- Endpoint/request summary.
- Actor/cohort used.
- Expected result.
- Actual result.
- Evidence link/path.
- Audit/log reference.
- Pass/fail.
- Notes.

The guide does not require download, artifact bytes, OpenAI upload, action import, dry-run/live execution, provider mutation, or provider validateOnly.
