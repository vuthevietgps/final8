# Scope

## In Scope

- Docs-only rerun result.
- Evidence quality classification.
- Repo-sync check.
- Canonical file rule review.
- Missing evidence record.
- Blocked controlled rollout decision review.

## Out Of Scope

- Production code.
- Test code.
- Deployment.
- Endpoint behavior changes.
- Download implementation or token.
- Artifact bytes, public URL, or storage path.
- OpenAI upload.
- Action import.
- Approval workflow.
- Dry-run/live execution.
- Provider mutation or provider validateOnly.
- New provider adapter.
- Phase 3.
