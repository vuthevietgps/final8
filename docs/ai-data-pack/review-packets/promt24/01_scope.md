# Scope

In scope:

- Direct authenticated download route.
- Service-level eligibility gates.
- Artifact file verification helper.
- RBAC/profile/section checks.
- Audit and observability events.
- Download rate limits.
- Focused controller/rate-limit/artifact tests.
- Minimal granular role-permission mapping for director and manager.

Out of scope and not implemented:

- Tokenized download.
- Download-token route.
- Public or signed storage URL.
- Artifact rendering.
- Raw/internal artifact download.
- Manifest-only placeholder streaming.
- OpenAI upload.
- Action import.
- Approval, dry-run, live execution.
- Provider mutation or validateOnly.
- New provider adapter.
- Phase 3.
