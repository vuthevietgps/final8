# Scope

In scope:

- Read Prompt 26 and Prompt 25 review result.
- Review Prompt 23-25 AI Data Pack download/rendering evidence.
- Run existing focused tests and build.
- Create manual ChatGPT Web acceptance documentation.
- Create ChatGPT Web analysis prompt.
- Record acceptance decision, test results, static checks, risks, and next recommendation.

Out of scope:

- Product code changes.
- OpenAI upload or OpenAI API calls.
- ChatGPT Web automation.
- Action import.
- Approval, dry-run, or live execution.
- Provider mutation or provider `validateOnly`.
- New provider adapter.
- Tokenized download.
- Public/signed storage URL.
- XLSX support.
- Phase 3.

Missing optional inputs are recorded in `ketquapromt26.json`.
