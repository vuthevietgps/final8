# Manual Loop Quality Rubric

Rubric file:

`docs/ai-data-pack/manual-transcript-quality-gate/04_manual_loop_quality_rubric.md`

The rubric defines pass/fail checks for:

- JSON artifact provenance
- redaction and token exposure
- uploaded JSON parseability
- expected finding detection
- evidence classification
- data quality warnings
- director-level reasoning
- advisory-only boundary
- no action execution
- no provider mutation
- no Phase 3

The rubric is for future manual ChatGPT Web Director JSON analyses.
