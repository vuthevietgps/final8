# Role/Cohort Verification Template

Main document:

- `docs/ai-data-pack/rollout-execution/public-create-status-role-cohort-template.md`

Cohorts covered:

- Director/admin.
- Manager.
- Investor status-only.
- Explicit permission user.
- Unbound role.
- `system_internal_worker`.
- Unassigned reviewer.

Each cohort includes:

- Allowed endpoints.
- Forbidden endpoints/surfaces.
- Required permissions/profile.
- Expected denial cases.
- Sample user id placeholder.
- Verified by.
- Verified at.

The template states:

- No anonymous users.
- No high-volume public cohort.
- No unbound external cohort.
