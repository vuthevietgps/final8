# Go/No-Go Signoff

Main document:

- `docs/ai-data-pack/rollout-execution/public-create-status-go-no-go-signoff.md`

Template includes:

- Release candidate identifier.
- Environment.
- Deployment window.
- Rollout cohort.
- Evidence folder/link.
- Required evidence links.
- Owner signoffs.
- Go criteria.
- No-go criteria.
- Conditional go notes.
- Rollback readiness confirmation.
- High-volume public exposure remains blocked.
- Download phase remains unopened.

Required signoff roles:

- Technical owner.
- Security/reviewer.
- Business/director owner.
- Operator/support owner.

If a role does not exist, the template requires a placeholder owner and delegated approver.
