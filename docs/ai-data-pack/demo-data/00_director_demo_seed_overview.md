## Safety Model

- Requires `ALLOW_DEMO_SEED=1`.
- Blocks `NODE_ENV=production`.
- Defaults to `--dry-run`.
- `--apply` resets deterministic demo ids first, then inserts the selected profile.
- `--reset-demo` deletes only deterministic demo `_id` allowlists generated by the large profile.
- Does not call external APIs.
- Does not call Google Ads API.
- Does not import, approve, validate, or execute ads actions.
- Does not store real secrets. Fanpage token fields use redacted non-secret placeholders because the existing schema has an `accessToken` field.
