# Scope

Target:

```text
low_inventory_best_seller
```

Allowed:

- inspect repo
- add read-only evidence rows
- add tests
- run build/static checks
- document result

Not allowed and not done:

- Action Draft Schema
- action import
- OpenAI API upload/call
- provider validation/execution/mutation
- approval workflow
- inventory mutation
- purchase/replenishment action
- production DB access
