# Threshold Contract

The proposed read-only threshold source contract includes:

- `threshold_key`
- `finding_key`
- `business_owner`
- `source_type`
- `source_module_or_collection`
- `field_path_or_config_key`
- `value_type`
- `unit`
- `default_allowed`
- `effective_from`
- `effective_to`
- `approval_status`
- `last_reviewed_at`
- `data_quality_status_impact`
- `confidence_impact`
- `fallback_behavior`
- `not_allowed_actions`

The contract is documentation only. It does not add schema, API, migration, or runtime code.
