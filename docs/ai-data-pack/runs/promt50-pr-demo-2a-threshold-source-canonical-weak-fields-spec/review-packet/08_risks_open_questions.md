# Risks And Open Questions

Key risks:

- Threshold constants are currently embedded in code.
- Some queried fields are candidate fields not guaranteed by schema, especially supplier quote approval/status.
- Receivable/payable terminology is ambiguous and must be business-owned before stronger conclusions.
- Labor and supplier reliability confidence cannot safely rise without policy and source hardening.

Key open question:

Which business owner approves and reviews each threshold source?
