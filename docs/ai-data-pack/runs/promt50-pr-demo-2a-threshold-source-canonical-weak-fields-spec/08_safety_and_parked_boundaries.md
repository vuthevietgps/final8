Prompt50 is read-only BA/spec work.

No application code was changed. No local, production, or server MongoDB data was read or mutated by Prompt50.

- action import
- approval workflow
- OpenAI API call
- ChatGPT Web API call
- provider validateOnly
- provider execution
- provider mutation
- dry-run/live execution
- Google Ads execution
- Facebook Ads execution
- Phase 3
- production DB/server MongoDB
- DB migration
- export/download endpoint expansion
- purchase order action
- supplier order action
- inventory/stock mutation
- supplier cost/price/COGS mutation
- order/revenue/cashflow mutation
- staffing/schedule/payroll/timesheet mutation
- business mutation of any kind

Any future threshold source registry must be read-only until separately authorized. Threshold records may explain evidence quality; they must not trigger actions.
