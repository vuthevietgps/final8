# Scope

In scope:

- Read-only overdue dealer/agent receivable settlement evidence.
- Existing Director JSON evidence surface.
- Focused tests and static checks.

Out of scope:

- Action Draft Schema
- Action import
- Provider validation/execution/mutation
- OpenAI API upload/call
- DB migration
- Collection action
- Agent/dealer blocking action
- Customer mutation
- Invoice/order mutation
- Payment mutation
- Cashflow mutation
- Ads mutation
