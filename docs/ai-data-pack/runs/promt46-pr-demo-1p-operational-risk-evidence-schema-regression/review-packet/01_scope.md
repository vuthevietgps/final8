# Review Scope

In scope:

- Positive schema regression guard.
- Data-quality/confidence enum guard.
- Finding-specific evidence minimum field guard.
- Existing read-only no-action-payload guard preservation.

Out of scope:

- Operations business logic changes.
- Provider/API execution.
- OpenAI/ChatGPT Web calls.
- DB migrations or data writes.
- Production MongoDB or server MongoDB.
