# Scope

In scope:

- Read-only labor overtime evidence.
- Existing Director JSON evidence surface.
- Focused tests and static checks.

Out of scope:

- Action Draft Schema
- Action import
- Provider validation/execution/mutation
- OpenAI API upload/call
- DB migration
- Staffing action
- Schedule action
- Payroll mutation
- Timesheet mutation
- Order/revenue mutation
- Cashflow mutation
- Ads mutation
