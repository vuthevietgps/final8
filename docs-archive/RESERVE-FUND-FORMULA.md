# QUỸ DỰ TRỮ - CÔNG THỨC MỚI
**Updated:** Feb 3, 2026

## 📋 TÓM TẮT

Quỹ Dự Trữ (Survival Buffer) được tính theo **2 yếu tố kết hợp**:
1. **Tích lũy**: 20% lợi nhuận thuần mỗi kỳ
2. **Target**: 3 tháng chi phí cố định (lương + vận hành)

## 🎯 CÔNG THỨC PHÂN BỔ LỢI NHUẬN

```
Lợi nhuận thuần = Doanh thu - Chi phí

Phân bổ:
├─ 45% → Quỹ Ads (tái đầu tư marketing)
├─ 35% → Quỹ Owner (owner rút về cá nhân)
└─ 20% → Quỹ Dự Trữ (tích lũy an toàn)

Total = 100% ✅
```

### Ví dụ:
```
Lợi nhuận tháng này: 100,000,000 VNĐ

Phân bổ:
├─ Ads Fund:     45,000,000 VNĐ (45%)
├─ Owner Fund:   35,000,000 VNĐ (35%)
└─ Reserve Fund: 20,000,000 VNĐ (20%)
```

## 🎯 TARGET RESERVE (Mục Tiêu)

```
Reserve Target = (Lương TB/tháng + Vận hành TB/tháng) × 3

Trong đó:
- Lương TB = Trung bình lương 3 tháng gần nhất
- Vận hành TB = Trung bình chi phí vận hành 3 tháng gần nhất
- × 3 = Đủ duy trì hoạt động 3 tháng
```

### Ví dụ:
```
Lương TB/tháng:      50,000,000 VNĐ
Vận hành TB/tháng:   20,000,000 VNĐ
────────────────────────────────
Chi phí cố định/tháng: 70,000,000 VNĐ

Reserve Target = 70,000,000 × 3 = 210,000,000 VNĐ
```

## 📊 RESERVE HEALTH (Sức Khỏe Quỹ)

```
Reserve Health % = (Reserve hiện tại / Reserve Target) × 100%

Status:
├─ >= 100% → ✅ SUFFICIENT (Đủ, an toàn)
├─  50-99% → ⚠️  BUILDING (Đang xây dựng)
└─  < 50%  → 🚨 CRITICAL (Nguy hiểm, cần tích lũy gấp)
```

### Ví dụ:
```
Scenario 1: Đủ Reserve
- Reserve hiện tại: 210,000,000 VNĐ
- Reserve Target:   210,000,000 VNĐ
- Health: 100% ✅ SUFFICIENT

Scenario 2: Đang tích lũy
- Reserve hiện tại: 140,000,000 VNĐ
- Reserve Target:   210,000,000 VNĐ
- Health: 67% ⚠️ BUILDING

Scenario 3: Thiếu nghiêm trọng
- Reserve hiện tại:  80,000,000 VNĐ
- Reserve Target:   210,000,000 VNĐ
- Health: 38% 🚨 CRITICAL
```

## 🛡️ SURVIVAL MONTHS (Số Tháng Duy Trì)

```
Số tháng = Reserve hiện tại / Chi phí cố định 1 tháng
```

### Ví dụ:
```
Chi phí cố định: 70,000,000 VNĐ/tháng

Scenario 1:
- Reserve: 210,000,000 VNĐ
- Survival: 210M / 70M = 3.0 tháng ✅

Scenario 2:
- Reserve: 140,000,000 VNĐ
- Survival: 140M / 70M = 2.0 tháng ⚠️

Scenario 3:
- Reserve: 50,000,000 VNĐ
- Survival: 50M / 70M = 0.7 tháng 🚨
```

## ⚡ WORKFLOW THỰC TẾ

### Tháng 1: Khởi đầu
```
Lợi nhuận: 100M
Phân bổ Reserve: 20M (20%)
Reserve tích lũy: 20M

Target: 210M
Health: 20M / 210M = 9.5% 🚨 CRITICAL
Survival: 0.3 tháng
```

### Tháng 2: Tiếp tục
```
Lợi nhuận: 120M
Phân bổ Reserve: 24M (20%)
Reserve tích lũy: 20M + 24M = 44M

Target: 210M
Health: 44M / 210M = 21% 🚨 CRITICAL
Survival: 0.6 tháng
```

### Tháng 5: Vượt ngưỡng 50%
```
Lợi nhuận tích lũy: 500M
Reserve tích lũy: 100M (20% × 500M)

Target: 210M
Health: 100M / 210M = 48% ⚠️ Building → gần đạt
Survival: 1.4 tháng
```

### Tháng 10: Đạt mục tiêu
```
Reserve tích lũy: 210M

Target: 210M
Health: 210M / 210M = 100% ✅ SUFFICIENT
Survival: 3.0 tháng
```

### Tháng 11+: Vượt mục tiêu
```
Reserve tích lũy: 250M

Target: 210M
Health: 250M / 210M = 119% ✅ SUFFICIENT (Dư)
Survival: 3.6 tháng

→ Có thể:
  - Giữ nguyên (an toàn hơn)
  - Điều chỉnh % phân bổ (giảm Reserve, tăng Ads/Owner)
  - Tăng target lên 6 tháng
```

## 📈 SO SÁNH 2 APPROACH

| | **Cách Cũ** | **Cách Mới** |
|---|---|---|
| **Tính Reserve** | Tĩnh (3 tháng chi phí) | Động (20% lợi nhuận) |
| **Tích lũy** | 1 lần | Liên tục mỗi tháng |
| **Target** | Không có | 3 tháng chi phí |
| **Đo lường** | Có/Không | % Health + Survival months |
| **Linh hoạt** | Thấp | Cao |
| **Động lực** | Không rõ | Rõ ràng (progress bar) |

## ✅ ƯU ĐIỂM CÁCH MỚI

1. **Tích lũy tự nhiên**: Mỗi tháng có lợi nhuận → tự động tăng Reserve
2. **Target rõ ràng**: Biết mình cần đạt bao nhiêu
3. **Đo lường được**: % health, số tháng survival
4. **Cân bằng**: Vừa đủ an toàn, vừa không giam giữ tiền quá nhiều
5. **Động lực**: Thấy progress tăng dần, có mục tiêu cụ thể

## 🎯 KẾT LUẬN

**Reserve Fund = Insurance Policy**
- Không phải để "dùng", mà để "an tâm"
- Target 3 tháng = Đủ để vượt qua khủng hoảng
- Tích lũy 20%/tháng = Đủ nhanh, không quá aggressive
- Health tracking = Biết mình an toàn đến đâu
